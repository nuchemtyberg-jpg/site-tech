Optimize the Photo Library feature for a mobile-first web app (iOS + Android). The goal is fast initial load, smooth scrolling, and instant-feeling image viewing even with thousands of photos.

Requirements (Performance + UX)

Thumbnail-first pipeline

Store and serve multiple sizes per image (ex: tiny blur placeholder, thumbnail, medium, original).

Photo grid loads thumbnails only.

Full image loads only when a user opens a photo viewer.

Capture date metadata

On upload, extract and store photo capture date from EXIF metadata.

If capture date is unavailable, fallback to upload date.

Every photo must have a normalized displayDate field.

Library sorting must be based strictly on displayDate.

Group and display photos chronologically by capture date.

Virtualized grid

Implement a virtualized/infinite scrolling grid (only render visible items).

Use an existing library (ex: react-virtuoso or react-window). Do not reinvent virtualization.

Lazy loading + prefetch

Use native lazy loading where possible.

Prefetch the next page of thumbnails and (when opening viewer) prefetch next/previous images.

Caching

Use strong caching headers for images.

Add a client cache layer (memory + IndexedDB or Cache API) for thumbnails.

Avoid re-downloading thumbnails when revisiting the library.

CDN / image optimization

Serve images through an image CDN or transformation layer (resize/compress WebP/AVIF when supported).

Ensure thumbnails are compressed aggressively and small (target: ~10–40KB typical).

Backend pagination + filters

API must be paginated (cursor-based preferred).

Support filters/sort (date, album, tags) without downloading everything.

Perceived performance

Show skeleton placeholders.

Use a blurred placeholder (LQIP) so images appear instantly while higher-res loads.

Do not block UI thread

Avoid heavy processing in the main thread.

Debounce scroll events, avoid layout thrashing, and keep rerenders minimal.

Metrics

Add basic performance logging: time to first thumbnails, scroll FPS jank count, image load time.

Provide a short checklist for verifying improvements.

Deliverables

Update the code to implement the above.

Provide a short explanation of what changed and why.

Include notes on any environment/config needed (CDN, storage, caching headers).

Constraints

Optimize for mobile networks.

Handle libraries with 10,000+ images.

Keep dependencies reasonable and well-known.
